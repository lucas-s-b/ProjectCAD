tut.welcome.title => 欢迎使用 ProjectCAD
tut.welcome.text => 本简短导览介绍窗口的主要部分。你可以随时跳过；帮助 > 教程可再次打开。首先，选择你的语言：
tut.menus.title => 菜单和命令搜索
tut.menus.text => 菜单栏包含文件（新建、打开、保存、导入和导出）、编辑、视图、帮助和插件。按 Ctrl+K 可按名称搜索任意命令。
tut.tools.title => 绘图工具
tut.tools.text => 左侧工具栏可在 2D 和 3D 视图之间切换，并包含绘图工具：直线、圆、矩形、圆弧、文字、标注、墙、门等。选择一个工具，然后在 2D 视图中单击点。Esc 可停止连续工具，例如直线或墙。
tut.snap.title => 捕捉和精确输入
tut.snap.text => 对象捕捉（F3）可捕捉端点、中点、圆心和交点；网格捕捉（F9）可捕捉网格。要输入精确点，请在状态栏的输入框中键入坐标：x,y 为绝对坐标，@dx,dy 为相对坐标，@d<a 为距离和角度。
tut.nav.title => 在视图中移动
tut.nav.text => 鼠标滚轮缩放。中键拖动平移，右键拖动环绕 3D 视图。视图 > 适应显示全部；视图 > 标准视图将相机转到前方、顶部、等轴测等方向。设置 > 导航可更改鼠标按键。
tut.panels.title => 面板
tut.panels.text => 草图、模型和装配面板位于右侧。草图列出对象、图层、属性和约束；模型包含草图、3D 特征和分析；装配包含组件、关节和物料清单。右上角的按钮用于切换面板；视图菜单可将面板停靠在左侧、右侧或底部。
tut.model.title => 从草图到实体
tut.model.text => 在 2D 中绘制一个闭合轮廓，然后在模型面板中通过拉伸、旋转、扫掠或放样将其变为实体，并添加圆角、倒角、抽壳和阵列。工具栏中的长方体、圆柱体和球体按钮可添加现成的实体。切换到 3D 查看结果。
tut.settings.title => 设置和快捷键
tut.settings.text => 设置（Ctrl+逗号）可更改主题、界面缩放、语言、鼠标导航以及每个键盘快捷键，并提供与其他软件一致的预设。导览结束：祝你设计愉快！
