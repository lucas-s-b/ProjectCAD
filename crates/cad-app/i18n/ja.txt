tut.welcome.title => ProjectCAD へようこそ
tut.welcome.text => この短いツアーでウィンドウの主な部分を紹介します。いつでもスキップでき、ヘルプ > チュートリアルで再び開けます。まず言語を選んでください：
tut.menus.title => メニューとコマンド検索
tut.menus.text => メニューバーにはファイル（新規、開く、保存、読み込み、書き出し）、編集、表示、ヘルプ、プラグインがあります。Ctrl+K を押すと、任意のコマンドを名前で検索できます。
tut.tools.title => 作図ツール
tut.tools.text => 左のツールバーで 2D と 3D のビューを切り替え、作図ツール（線分、円、長方形、円弧、文字、寸法、壁、ドアなど）を使えます。ツールを選び、2D ビューで点をクリックします。線分や壁のような連続ツールは Esc で終了します。
tut.snap.title => スナップと正確な入力
tut.snap.text => オブジェクトスナップ（F3）は端点、中点、中心、交点を捉え、グリッドスナップ（F9）はグリッドを捉えます。正確な点はステータスバーの入力欄に座標を入力します：x,y は絶対、@dx,dy は相対、@d<a は距離と角度です。
tut.nav.title => ビューの操作
tut.nav.text => マウスホイールでズーム。中ドラッグでパン、右ドラッグで 3D ビューをオービットします。表示 > 全体表示ですべてを表示し、表示 > 標準ビューでカメラを正面、上、等角などに向けます。設定 > ナビゲーションでマウスボタンを変更できます。
tut.panels.title => パネル
tut.panels.text => スケッチ、モデル、アセンブリのパネルは右側にあります。スケッチはオブジェクト、レイヤー、プロパティ、拘束を、モデルはスケッチ、3D フィーチャ、解析を、アセンブリはコンポーネント、ジョイント、部品表を扱います。右上のボタンでパネルを切り替え、表示メニューで左・右・下にドッキングできます。
tut.model.title => スケッチからソリッドへ
tut.model.text => 2D で閉じたプロファイルを描き、モデルパネルで押し出し、回転、スイープ、ロフトによってソリッドにし、フィレット、面取り、シェル、パターンを追加します。ツールバーの直方体、円柱、球のボタンで既成のソリッドを追加できます。結果は 3D に切り替えて確認します。
tut.settings.title => 設定とショートカット
tut.settings.text => 設定（Ctrl+カンマ）では、テーマ、UI の拡大率、言語、マウス操作、すべてのキーボードショートカットを変更でき、他のソフトに合わせたプリセットもあります。ツアーは以上です。設計を楽しんでください！
